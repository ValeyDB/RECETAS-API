# RECETAS-API
Una API con las funciones CRUD, basada en un repositorio de recetas en MySQL

    git clone 
Usado para copiar un repositorio remoto a su computadora.

    git merge
Usado para combinar ramas (útil al trabajar en equipo).

    git pull
Trae cambios del repositorio remoto.

    git push
Envía sus cambios al repositorio remoto.

    git branch
Manejo de ramas para trabajo colaborativo o en paralelo.
